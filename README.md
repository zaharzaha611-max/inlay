# Inlay — Fabric 1.21.11

Вставляйте текстуру любого блока в грань другого блока (эффект «утопленного» блока, как в Backrooms).

## Как пользоваться
1. Скрафтите «Резец для вставок» (железный слиток + палка по диагонали) или возьмите в творческом меню (вкладка «Инструменты»).
2. Резец — в основную руку, любой блок — в левую (off-hand).
3. ПКМ по грани любого цельного блока: в эту грань «утапливается» блок из левой руки.
   В разные грани одного блока можно вставлять разные блоки.
4. Shift + ПКМ резцом по грани достаёт вставленный блок. Когда вставок не осталось, исходный блок возвращается.
5. Если сломать блок со вставками в выживании, выпадают и хост, и все вставки.

## Сборка
- Java 21, IntelliJ IDEA (или Gradle 8.14+).
- Нет gradle wrapper: скопируйте `src/` в свежий шаблон с https://fabricmc.net/develop (1.21.11)
  или выполните `gradle wrapper` в этой папке.
- `./gradlew build`, jar появится в `build/libs/`.
